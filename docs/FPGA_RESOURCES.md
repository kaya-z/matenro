# FPGA 資源の使用状況 (記録)

Tang Nano 9K (`GW1NR-LV9QN88PC6/I5`、Gowin IDE の `gw_sh`、`run all` = 合成 + 配置配線)。測った日: **2026-11-08**。

**(Tang Nano 20K の版は 7 章。実機で動く最新の資源とタイミングは、そちらです。)** **値は、ディスクの非同期モード (PSRAM のマスタ 4、割り込み、マップの保持) と起動メッセージ `Matenro Memory` を入れた起動 ROM 版 (`fpga/tn9k/scripts/build.sh boot`、`TAG=_async`) のものです。**
このビットストリームは実機のフラッシュに入っていて、OS-9 Level 2 が起動し、`duo` と非同期のディスクが動いています。
漢字ローダは 2026-11-01 に削除済み、ACIA の割り込み (2026-11-06)、共有 RAM (2026-11-07)、ディスクの非同期モード (2026-11-08) は入っています。

## 5. 空きと今後の余地

* 9K の残りは Logic で約 776 (9%)、CLS で約 178 (4%)、BSRAM で 18 ブロック (36KB) です。**HDMI (約 2,000 LUT) は載りません**。20K のボードには載せて動いています (7 章)。
* 共有 RAM を 16KB に広げると、BSRAM はあと 4 ブロック、LUT は数十増えます。ブロック数は足りますが、CLS が 96% で、Fmax の余裕が 1.1MHz です。配置配線の結果次第です。
* 8088 (3,000〜6,000 LUT の見積もり) は 9K には載りません。20K に載せて動いています (7 章: 8088 側は約 1,600 LUT、BSRAM 10)。

### 7.5 空きと今後の余地

* **残り**: Logic 約 8,600 (41%)、CLS 約 2,660 (25%)、BSRAM 13 ブロック (約 29 KB)、I/O 43 ポート、**rPLL は 0** (2 つとも使用中)。
* **載せられそうなもの**: 描画の関数 (6809 のソフトで足りる: 資源は要らない)、8088 / Z80 から描く経路 (XLINK のレジスタの追加で、数十〜数百 LUT)、RTC、キーボード (USB はない: UART 経由)、サウンド (PWM、数十 LUT)。**フレームバッファの 640 x 480、色数を増やす、は BSRAM と SDRAM の時間が足りない。**
* **気をつけること**: ① CLS が 75%、`clk81` の余裕が 0.2 MHz なので、機能を足すと配置配線がタイミングを満たさなくなることがある。② PLL がもう使えないので、別のクロックが要る機能 (別の画素クロック、音声など) は、HDMI の 126 MHz から分周するか、システムの PLL の別の出力を使う。③ SDRAM の時間: フレームバッファを出している間、画面が約 28% を使うので、8088 (4.9 MHz) の速さがその分だけ遅くなる (バースト読み出しは、実機で動かなかった)。

### 7.6 再現の手順

```sh
# 実機のビットストリーム: SRAM に書く (-m。電源を切ると消える。フラッシュは -f)
PLACE=0 TAG=_x fpga/tn20k/scripts/build.sh boot             # 結果: fpga/tn20k/build/boot_x/impl/pnr/matenro20k_boot.fs
openFPGALoader -m fpga/tn20k/build/boot_x/impl/pnr/matenro20k_boot.fs
# 合計: impl/pnr/matenro20k_boot.rpt.txt、タイミング: matenro20k_boot_tr_content.html、モジュール別: impl/gwsynthesis/matenro20k_boot_syn_resource.html
# 8088 だけ: SUBS=8088、HDMI なし: HDMI=0、漢字なし: KANJI=0
```
