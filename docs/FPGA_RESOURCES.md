# FPGA 資源の使用状況 (記録)

Tang Nano 9K (`GW1NR-LV9QN88PC6/I5`、Gowin IDE の `gw_sh`、`run all` = 合成 + 配置配線)。測った日: **2026-11-08**。

**値は、ディスクの非同期モード (PSRAM のマスタ 4、割り込み、マップの保持) と起動メッセージ `Matenro Memory` を入れた起動 ROM 版 (`fpga/tn9k/scripts/build.sh boot`、`TAG=_async`) のものです。**
このビットストリームは実機のフラッシュに入っていて、OS-9 Level 2 が起動し、`duo` と非同期のディスクが動いています。
漢字ローダは 2026-11-01 に削除済み、ACIA の割り込み (2026-11-06)、共有 RAM (2026-11-07)、ディスクの非同期モード (2026-11-08) は入っています。

## 2. タイミング (`impl/pnr/matenro_boot_tr_content.html`)

| クロック | 制約 | 実際の Fmax | 負のスラック (setup / hold) |
|---|---|---|---|
| `clk81` (システム 67.5MHz) | 67.5MHz | **67.528MHz** | なし / なし |
| `E` (6809 のバスクロック) | 1.875MHz | 約 21.6MHz | なし / なし |

**余裕は 0.03MHz しかありません。** 同じ RTL に近い 1 つ前のビルド (`Matenro` の見出しの前) は 68.012MHz でした。**配置配線の結果は RTL の小さな変更でも変わります** (同じ RTL でも `PLACE` は効きません)。共有 RAM を入れた最初の配置配線は 63.8MHz (負のスラック -1.78ns、4 経路) で通らず、`xlink.v` の `smmu_rd` の後ろに FF を 1 段足して通しました。必ずビルドのたびに `Total Negative Slack Summary` を見てください。

## 5. 空きと今後の余地

* 9K の残りは Logic で約 805 (9%)、CLS で約 182 (4%)、BSRAM で 18 ブロック (36KB) です。**HDMI (約 2,000 LUT) は載りません**。20K のボードなら載ります。
* 共有 RAM を 16KB に広げると、BSRAM はあと 4 ブロック、LUT は数十増えます。ブロック数は足りますが、CLS が 96% で、Fmax の余裕が 0.03MHz しかありません。配置配線の結果次第です。
* 8088 (3,000〜6,000 LUT の見積もり) は 9K には載りません。20K が要ります。
